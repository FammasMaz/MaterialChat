# M3 Expressive pass 2 — reference notes (home + settings + sheets)

Verified against `material3-android 1.5.0-alpha15` (javap on the extracted AAR) and `androidx.graphics.shapes 1.1.0`.

1. **compose-material3 1.5 alpha release notes** — `ButtonGroup`/`ToggleButton` connected shapes (`ButtonGroupDefaults.connected*ButtonShapes`, `animateWidth`), `SplitButtonLayout` + `SplitButtonDefaults.LeadingButton/TrailingButton(checked)`, `HorizontalFloatingToolbar`, `FloatingActionButtonMenu`, `LoadingIndicator`/`ContainedLoadingIndicator`, `LinearWavyProgressIndicator`, `MaterialShapes`, `ListItemDefaults.segmentedShapes`. All present in the AAR; `FloatingAppBar` was renamed to `FloatingToolbar`, `SplitButton` to `SplitButtonLayout`.
2. **m3.material.io shape morph** — morph only between `RoundedPolygon`s (`Morph` in graphics-shapes 1.1.0, `Morph.toPath(progress)`), drive progress with a *spatial* spring. Took: press/arm morphs are driven by one 0..1 spring, never two competing animations.
3. **m3.material.io motion physics** — spatial springs (position/size/corners, may overshoot) vs effects springs (color/alpha, critically damped). Took: new tokens in `Motion.kt` keep this split (`thresholdPop` spatial, nothing new on the effects side).
4. **M3E lists guidance** — segmented list items use outer radius on the stack edge, 4dp seams, 2dp gap; the pressed item morphs to the full radius. Already in `SegmentedRowShapes`; pass 2 applies the same per-position idea to swipe action containers (leading action rounds its outer edge, trailing action rounds its outer edge).
5. **M3E slider** — 1.5 `Slider` already draws the wide track + stop indicator; the expressive touch is a thumb that widens on press and a visible thumb/track gap (`SliderDefaults.Track(thumbTrackGapSize, trackInsideCornerSize)`, `Thumb(thumbSize)`). Took: one shared `ExpressiveSlider` in `ui/components`.
6. **M3E switch** — thumb icon when the state has meaning, icon swap on a spring, no fade-only crossfade. Took: `ExpressiveSwitch` thumb icon now scales in on the spatial spring.
7. **material-components-android `material3-expressive` catalog** — split buttons pair a primary action with a chevron trailing segment whose inner corners stay small and whose chevron rotates when open. Took: `ProviderCard` actions.
8. **sameerasw/essentials, Read You, Metrolist** — each uses `LoadingIndicator` for every indeterminate spinner and `LinearWavyProgressIndicator` for downloads; dialogs keep 28dp and only animate entry (scale from ~0.9 + fade). Took: replace remaining `CircularProgressIndicator`/`LinearProgressIndicator` in owned files, add a dialog entrance modifier (exit cannot be animated with `AlertDialog`, so it is not faked).
9. **FloatingActionButtonMenu / HorizontalFloatingToolbar** — the home "+" lives in `MainActivity`'s overlay toolbar (not in `ui/screens/conversations/**`); `HomeListInsets.bottomClearance` already clears it. Not changed in this pass; recorded in the report.
10. **API 26** — `MaterialShapes`/`Morph` are pure path math (no shader), `LoadingIndicator` and the wavy indicators draw with Canvas only; nothing added here needs a shader or blur fallback.
